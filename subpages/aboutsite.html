Asobi Lab. の設計と技術について

設計コンセプト

このサイトは、単なる情報発信の場ではなく、触れて楽しめる体験型の構成を目指しています。

JavaScriptの複雑性を抑え、CSS変数を中心に動的で一貫したUXを実現しています。複数のテーマを切り替えることで、同じHTMLが異なる印象を持つ仕組みを構築しました。

技術スタック

フロントエンド

  • HTML5 - セマンティックな構造設計
  • CSS3 + CSS Variables - テーマシステムの基盤
  • JavaScript - 必要最小限のロジック

アーキテクチャ

  • ファイル分割 - ページ別・機能別CSSと共通スタイル
  • CSS動的ロード - URLに応じて必要なCSSのみ読み込み
  • localStorage連携 - テーマ設定のブラウザ保存
  • インタラクション - スクロール出現・メニュー・イースターエッグなど

テーマシステム

このサイトの特徴の一つは、複数のテーマを瞬時に切り替えられることです。

各テーマは、以下の4つのカラー変数で構成されています：

  • --main-color - 主要なアクセントカラー
  • --balance-color - 補助的なカラー
  • --variation-color - テキスト色
  • --accent-color - 背景色

これらの変数がCSS内で参照されるため、新しいテーマを追加するだけで、すべてのページが自動的に新しい色で表現されます。

アニメーションとインタラクション

見た目の装飾にとどまらず、UXの直感性を高めるためのアニメーションを採用しています。

  • 粒子メニュー - 長押し / 3回タップで開く放射メニュー
  • スクロール出現 - セクションが滑らかに表示される
  • イースターエッグ - 隠しコマンドによる演出
  • テーマ切り替え - 世界観の変化を視覚的に体験

パフォーマンス

体験を損なわないよう、外部ライブラリは最小限に抑え、CSS Variables と軽量なJavaScriptで動作するよう設計しています。
