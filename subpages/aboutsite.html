🎯 設計コンセプト

このサイトは、単なる情報発信の場ではなく、触って楽しい見て面白い、玉手箱のような構成としております。

JavaScriptの複雑性を排除し、純粋なCSS変数の力で、動的で美しいUXを実現。多色の「世界観」を切り替えることで、同じHTMLが全く異なる表情を持つシステムを構築しました。

🛠️ 技術スタック

フロントエンド

  • HTML5 - セマンティックで意図的な構造設計
  • CSS3 + CSS Variables - 多色のテーマシステムを完全制御
  • JavaScript - ミニマルで効率的なロジックのみ

アーキテクチャ

  • ファイル分割 - ページ別・機能別CSS + 共通スタイル
  • CSS動的ロード - URLを検出して必要なCSSだけ読む
  • localStorage連携 - テーマをブラウザに記憶
  • 遊び心エンジン - スクロール出現・トースト・イースターエッグ

🎨 多色のテーマシステム

このサイトの大きな特徴は、多種類の異なる「世界観」を瞬時に切り替えられることです。

各テーマは、以下の4つのカラー変数（CSS）で構成されています：

  • --main-color - 主要なアクセントカラー
  • --balance-color - 補助的なカラー
  • --variation-color - テキスト
  • --accent-color - 背景色

これらの変数がCSS内で参照されるため、新しいテーマを追加するだけで、すべてのページが自動的に新しい色で表現されます。

✨ アニメーション哲学

単なる「見た目の面白さ」ではなく、UXの直感性を高めるためのアニメーションを採用。

  • 粒子メニュー - 長押し / 3回タップで開く放射メニュー
  • スクロール出現 - セクションがふわっと現れる
  • イースターエッグ - ↑↑↓↓←→←→BA でコンフェッティ
  • テーマ切り替え - 世界観の変化を視覚的に体験

🚀 パフォーマンス

「面白さ」と引き換えに体験が損なわれては本末転倒。外部ライブラリは最小限、CSS Variables と軽量JSで高速を保っています。
